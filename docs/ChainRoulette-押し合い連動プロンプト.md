■ 目的
バトクラ（ギフト攻城戦）の押し合いモードを、配信画面の上に小窓で出している。
- 豆の砦（配信者側）が落ちたら → ChainRoulette で「罰ゲームガチャ」を1回まわし、結果をバトクラに返す
- 敵の砦を落としたら → ChainRoulette の「2倍タイム」を発動する

■ バトクラ側（もうできている。gift-war.onrender.com）
鍵は、今の「バトクラ 2倍タイム」と同じもの（設定の bkServer / bkKey。1.17.133〜）。

1. お知らせを読む：GET {bkServer}/api/pevents?k={bkKey}&since={前に読んだ last}
   返り値：{"ok":true,"last":12,"running":true,"events":[{"id":12,"t":"fall","at":1794905531613,"top":["ロッキー",120],"clear":false}]}
   - t = "fall"（豆の砦が落ちた）／"capture"（敵の砦を落とした）
   - top = いちばん攻めた人 [名前, コイン]（fall のときだけ。いないと null）
   - since を付けないで呼ぶと、events は空で last だけ返る（アプリを起動したときは、まずこれで last を覚える。昔の出来事をやり直さないため）
   - 鍵が違うと 403
   - 数秒（2〜3秒）ごとに読む。ネットが切れても、つながったら since から続きを読めばよい

2. 罰ゲームの結果を返す：GET {bkServer}/api/presult?k={bkKey}&text={罰ゲームの名前（URLエンコード）}
   - 小窓に「罰ゲーム：電撃」と出て、バトクラの設定の秒数（10〜120秒）のあとに砦が復活する
   - 30秒以内に返らないときは、バトクラ側が勝手に復活の秒読みを始める

■ ChainRoulette でしてほしいこと
1. 「バトクラ」の設定（bkServer / bkKey のところ）に「押し合いの落城・攻略と連動する」のON/OFFを足す
2. ONのあいだ、上の pevents を数秒ごとに読む（配信していないとき・OFFのときは読まない）
3. fall が来たら：
   - 「罰ゲームガチャ」のルーレットを1回まわす（どのルーレットを使うかは設定で選べるように）
   - 止まったマスの名前を presult で返す
   - 罰ゲームの中身（例：レモン汁／苦丁茶／電撃／混ぜ（苦丁茶＋レモン汁））と確率は、ルーレットのマスと重みで変えられるようにする
4. capture が来たら：アプリの「2倍タイム」を発動（秒数は設定で。今の手動2倍タイム bonus/manual と同じもの）
5. ログに「🏰 豆の砦が落ちた → 罰ゲームガチャ」「🏰 敵の砦を攻略 → 2倍タイム」と出す
6. 同じ id を2回動かさない

■ 守ること
- 返信は日本語で。決めることは番号つきの選択肢で
- 英語の画面の操作を説明するときは、ボタン名に日本語の意味を添える
- 鍵（bkKey）はログや画面にそのまま出さない（●●●● にする）
- 本番の ChainRoulette は配信していないときだけ入れ替える
